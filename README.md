## 🚀 Como ativar o GitHub Pages

1. Vá em **Settings** do repositório
2. Selecione **Pages** no menu lateral
3. Em "Source", escolha **main** branch
4. Clique em **Save**

Seu site estará disponível em: `https://marcosmattos0704-star.github.io/Marcos-e-Juliana-`
